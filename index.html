Projects

Selected UI/UX work with design thinking process

Sawit Detection App — AI-Powered Oil Palm Monitoring App

A mobile app UI design for monitoring oil palm plantations using drone and AI technology. Designed to help plantation supervisors detect fruit bunch ripeness in real-time and generate block-by-block harvest reports.

Figma UI Design Wireframing Prototyping Mobile App
📋 Case Study
🎯 Brief

Design challenge given by PT Makerindo as part of internship selection. Task: design 3 core screens of a mobile app for oil palm plantation supervisors who need fast, data-driven decisions in the field.

👤 Target User

Plantation supervisors and operational managers with high mobility who need real-time data from drone-based AI detection.

🔍 Design Problem

How to present complex drone + AI data (live camera feed, ripeness detection, harvest reports) in a mobile interface that is fast to read and easy to act on in the field?

✏️ Design Process
1. Read & Analyze Brief 2. Define User Needs 3. Sketch User Flow 4. High-Fidelity UI in Figma
📱 Screens Designed
Dashboard (weather, drone status, ripeness summary) Live Drone View (real-time AI detection with bounding box) Report & Recap (charts, flight history per block)
💡 Design Decisions

Used a dark green color palette to reflect the plantation context and ensure good contrast outdoors. Priority information (ripeness count, drone battery, emergency button) placed in thumb-reachable zones for mobile usability.

SIMKOS — Boarding House Management System

A desktop web application UI for managing boarding house rooms, rental transactions, and income reports — with role-based access for Admin, Cashier, and Owner.

Figma UI Design Wireframing Desktop Web App Role-Based UI
📋 Case Study
🎯 Brief

Final competency exam project (UKK) — design and build a boarding house rental system. Designed the full UI in Figma before implementation, covering all 3 user roles: Admin, Cashier, and Owner.

👤 Target Users

3 distinct user roles: Admin (manages rooms & users), Cashier (handles transactions), Owner (monitors reports & activity logs).

🔍 Design Problem

How to design a single system that serves 3 different user roles with different tasks and permissions, while keeping the interface clean and easy to navigate for each role?

✏️ Design Process
1. Analyze Requirements 2. Define User Roles & Flows 3. Design Mockup in Figma 4. Implement to Code
🖥️ Key Screens
Admin Dashboard (room stats, user status) Room Management (card layout with availability status) Transaction History Owner Report View
💡 Design Decisions

Designed separate dashboard views per role so each user only sees what's relevant to their task. Used card-based layout for room data to make availability status instantly readable at a glance.
